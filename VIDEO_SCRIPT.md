# Video script: Shadowfolk (target 2:45, hard limit < 3:00)

**Capture:** Quest 3 / 3S casting or on-device recording (Settings → Camera → Record video, 1080p, 30 fps),
seated in a warm, dim room with a plain wall behind the parchment. Record **mixed-reality footage** (passthrough
visible) for the hero shots. A backup for every shot can be screen-recorded from `?demo=1` in a desktop browser
(1920×1080) if a headset take fails.

**Audio:** game audio only (all synthesized) plus an optional quiet voice-over. No licensed music.

## Shot checklist
- [ ] Hero rabbit in the first 8 seconds, with passthrough visible
- [ ] One take of the real cold start with no cuts (button → rabbit)
- [ ] Bird flapping visibly faster when fingers wiggle
- [ ] Dog bark synced with the pinky snap
- [ ] Ending firefly swarm held for 5+ seconds
- [ ] All four one-handed alternatives
- [ ] Journal + palm-up pause menu
- [ ] Total length under 3:00 (aim 2:45–2:52)

## Recording tips
- Dim the room lights slightly: the lantern glow and shadows read better.
- Keep hands about halfway between the lantern and the wall (30–40 cm from your face) for crisp shadows.
- Re-center (palm up → Recenter) before each take so the wall is straight ahead.
- For the browser backup: open `?demo=1` in Chrome at 1920×1080, click once to enable audio, and screen-record.
